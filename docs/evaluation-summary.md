# QVeris 金融 Agent 评测报告 · 核心指标与结论（全量 50 题）

> 面向金融 / AI / 产品 / 运营的跨团队摘要。逐任务明细数据与完整方法学见评测代码仓的批次报告（`reports/qveris-finance-benchmark/claw-runs/D4_STANDARD30_REPORT_20260712.md`、`FULL50_REPORT_20260716.md`）。
> 最后更新：2026-07-16。本次更新：任务集扩展至**全部 50 道、100% 专家验证**，并给出全量合并口径的锁定结论。

## 摘要

本报告基于对 QVeris 数据与工具网关（金融为其首个深耕垂类）的**配对 A/B 消融评测**——同一 Agent、同一任务集，唯一变量为"是否接入 QVeris"。全量 50 题（每题 ×3 变体 ×3 重复）核心结论：

- 接入 QVeris 后金融 Agent 的**回答质量提升具备统计显著性**：100 分制下 CLI **+6.6**、MCP **+6.7**，95% 置信区间不含零，最小可检测效应（MDE）低于增益。
- 在**缓存感知成本核算**下（部署级真实 GPT-5.5 计价），真实成本开销为 **1.52~1.67 倍**（而非原始 token 口径的约 4.7 倍）。
- 据此，三类使用画像 × 两种接入形态共 **6 格全部判定为"值得部署"**（最省钱敏感的隔夜批处理亦有 +3.3 以上余量）。

## 一、评测方法

- **对照设计**：对照组 = 仅公开网页检索；实验组 = 接入 QVeris（含 CLI 与 MCP 两种接入形态）。控制 Agent、任务、评分完全一致；唯一变量为是否接入 QVeris。
- **任务集**：**50 道**金融场景任务（财报摘要、异动侦测、行情仪表盘、多源投研整合等），**验收标准全部由金融领域专家逐题制定并验证**（四轮多专家问卷交叉验证与融合，覆盖率 100%）。每道 ×3 变体 ×3 trial = 450 次作答（本报告为 D4 的 30 题 + D4b 的 20 题合并口径，同一运行时与计价）。
- **评分体系（双层，取最小值）**：确定性规则层（5 维度：准确性 / 可信来源 / 可用性 / 效率 / 规范性，满分 100）+ LLM 语义裁判层（GLM-5.2），终值 = min(规则分, 裁判分)，以裁判层为主口径、规则层为保守下限。
- **统计口径**：以"任务"为推断单元，任务聚类配对差 95% 置信区间 + 分层 bootstrap；报告最小可检测效应（MDE，当前样本量 80% 功效下能可靠区分的最小效应）。

## 二、质量增益（Quality Lift）

质量增益 = 实验组相对对照组的评分提升（分）。全量 50 题为当前锁定口径；D3（15 题，旧运行时）作历史参照。

| 批次 / 口径 | QVeris CLI | QVeris MCP | 显著性 |
|---|---|---|---|
| **全量 50 · 裁判层（主口径）** | **+6.6**（CI 4.3~9.0，MDE 3.3） | **+6.7**（CI 4.2~9.2，MDE 3.5） | 均显著 |
| 其中 D4（30 题参照） | +7.4（CI 3.9~10.9） | +8.0（CI 4.6~11.4） | 均显著 |
| 其中 D4b（新增 20 题） | +5.5（CI 2.5~8.5） | +4.7（CI 0.9~8.4） | 均显著（MCP 边际） |
| D3（15 题·旧运行时参照） | +11.9（CI 5.5~18.4） | +13.5（CI 7.8~19.1） | 均显著 |

逐任务方向性：全量 50 题中 **CLI 42/50 为正、MCP 41/50 为正**。全量点估计低于 D4/D3 属预期——任务集越大越难、实时抓取类占比更高（该类边际价值最低，见分层）；不变结论是效应在完整验证集上仍稳健显著、CI 明显更窄（MDE 降至 3.3~3.5）。

### 分层质量增益（按时效性，全量 50 · 裁判层）

T1 = 实时抓取（取当前数值）；T2 = 历史查证（检索并抽取已披露资料）；T3 = 复杂调查（多步查证、跨源交叉比对）。

| 任务类型 | 样本量 n | QVeris CLI | QVeris MCP |
|---|---|---|---|
| T2 历史查证 | 20 | +8.4（CI 4.2~12.5）显著 | +8.3（CI 4.3~12.4）显著 |
| T3 复杂调查 | 19 | +6.3（CI 3.6~8.9）显著 | +6.6（CI 3.7~9.5）显著 |
| T1 实时抓取 | 11 | +4.1（CI 跨零，高方差） | +3.8（CI 跨零，高方差） |

**价值定位清晰**：增益集中在 T2/T3 这类"需要可靠多源数据 + 多步推理"的复杂任务（两变体均显著且 CI 收紧）；T1 简单取数边际价值有限、方差大（正向但不显著）。这与产品直觉一致——QVeris 的价值在"查得全、查得准、能交叉验证"，而非替代一次性取数。

**稳定性**：实验组回答的重复间标准差显著低于对照组（组内 sd：对照 7.3 → CLI 5.9 → MCP 5.7），即 QVeris 同时降低输出方差约 1.25 倍——对可交付场景，"稳定"与"更高"同等重要。

## 三、成本分析 · 缓存感知核算

原始输入 token 口径会严重误读成本：运行时对工具返回结果启用激进**前缀缓存**，实验组 83~86% 的输入 token 属缓存复用（按输入价约 10% 计费），不应按全价计入。区分"全价新增 token"与"折价缓存 token"后（部署级真实 GPT-5.5 现价：输入 $5/1M、输出 $30/1M、缓存读 0.10×、QVeris $0.02/次）：

| 指标（每任务均值） | 对照组 | QVeris CLI | QVeris MCP |
|---|---|---|---|
| 原始输入 token | 244k | 1138k（×4.66） | 1163k（×4.77） |
| 缓存命中率 | 29% | 86% | 83% |
| 全价新增（未缓存）token | 174k | **163k（×0.94）** | 195k（×1.12） |
| LLM 费（美元，缓存感知） | 1.25 | 1.76 | 1.84 |
| + QVeris API 费（美元） | 0 | 0.14 | 0.25 |
| **缓存感知总成本（美元）** | **1.25** | **1.90（×1.52）** | **2.09（×1.67）** |
| 端到端延迟 | 325s | 445s（×1.37） | 373s（×1.15） |

**关键读数**：QVeris CLI 的全价新增 token 实际为对照组的 **0.94 倍（更低）**——其庞大的原始 token 总量几乎全是廉价缓存复读，而对照组较小的总量多为全价新鲜检索。真实边际成本为 **1.52×（CLI）/ 1.67×（MCP）**，而非原始口径的约 4.7×。按原始 token 口径估算会把 QVeris 成本高估约 3.5 倍，进而误判 ROI。

## 四、综合价值判定 · 使用画像加权净效益

借鉴成本效益分析（CEA）净效益框架：为质量、延迟、成本设定画像特定兑换率，折算为单一净效益并给出"值得部署 / 中性 / 不值"判定。

判定式：`净效益 = 质量增益 − 延迟权重 × Δ延迟% − 成本权重 × Δ成本%`。三类画像（延迟权重 / 成本权重）：交互分析师 10/2、日常研究 3/2、隔夜批处理 0/5；判定带 τ=1。成本轴的选取直接决定结论——下表对照两轴（全量 50，评测框架原生输出）：

| 使用画像 | 原始 token 轴（全价计缓存·失真） | 缓存感知成本轴（真实） |
|---|---|---|
| 交互分析师（重延迟） | CLI −4.4 不值 / MCP −2.3 不值 | **CLI +1.9 值得 / MCP +3.8 值得** |
| 日常研究（均衡） | CLI −1.8 不值 / MCP −1.3 不值 | **CLI +4.5 值得 / MCP +4.9 值得** |
| 隔夜批处理（重成本） | CLI −11.7 不值 / MCP −12.1 不值 | **CLI +4.0 值得 / MCP +3.3 值得** |

**结论**：真实缓存感知成本轴下，三画像 × 两接入形态共 6 格**全部判定为"值得部署"**（含最省钱敏感的隔夜批处理，余量 +3.3 以上）；原始 token 轴则 6 格全负。差异完全源于成本口径——将缓存复用 token 按全价计入会系统性高估成本、进而反转结论。两轴间的巨大差距对计价稳健，仅 τ=1 判定带附近的格会随费率微动。

### 结论的适用边界（严谨声明）

- **策略条件性**：成本优势与运行时缓存策略强相关（本批命中率 83~86%）。成本（及价值判定）是"工具 × Agent 策略"的联合属性，非工具单独固有——判定条件于所评运行时环境，不宜无条件外推。
- **计价为行业代理**：缓存读取按输入价 10% 计，为主流前缀缓存通行折扣，非特定计费合同；配置部署模型真实费率可得可交付验收判定。
- **跨批次可比性**：全量 50 由 D4（30 题）+ D4b（20 题）在**同一运行时（codex CLI 0.144.1、gpt-5.5 @ xhigh）与同一计价**下合并，质量与成本口径一致；D3（15 题）为旧运行时，仅质量增益可参照、成本不可直接比较。
