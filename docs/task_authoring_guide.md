# Task Authoring Guide

Good long-horizon tasks should be realistic, auditable, and difficult enough to
separate weak automation from professional-grade agent execution.

## Requirements

- Define a concrete user objective.
- Include realistic input artifacts or data access assumptions.
- Specify deliverables and acceptance criteria.
- Avoid hidden subjective requirements that scorers cannot audit.
- Include a rubric with clear partial-credit rules.
- Declare whether external tools, web access, or QVeris calls are allowed.

Finance is the first required domain. Media and public-opinion tasks should
follow the same structure after finance reaches v1.
