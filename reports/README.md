# Published reports

This directory contains selected, reviewable benchmark reports. Generated run
directories, transcripts, raw provider responses, local ledgers, and private
holdout results are excluded from version control.

A public report must state whether it is observed, predicted, simulated,
partial, or final. It must identify the benchmark version, task cohort,
execution date, systems and variants under test, judge configuration, sample
size, and known limitations. Results apply only to the documented versions and
conditions; they are not general agent leaderboards.

Historical reports may use earlier repository names or evaluation protocols.
Their filenames and claims should not be treated as current project status.
